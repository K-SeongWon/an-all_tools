# 앱 서명 키 (공개 키)

`anall-public.jks` 는 안올툴 APK 서명 키다. **일부러 공개 저장소에 넣었다.**

| 항목 | 값 |
| --- | --- |
| 형식 | PKCS12, RSA 4096, 유효기간 100년 |
| alias | `anall` |
| 비밀번호 (store / key) | `anall-public-key` |
| 인증서 | `CN=An-All Tools` (개인정보 없음) |

## 왜 공개했나

- 안드로이드는 **같은 키로 서명된 APK 만 업데이트로 설치**한다. 키가 바뀌면 앱을 지우고 다시 설치해야 한다.
- 키를 저장소에 두면 PC 빌드든 GitHub Actions 빌드든 항상 같은 키로 서명되고, 키를 잃어버릴 일도 없다.
- 안올툴은 계정·결제·개인 데이터가 없는 재미용 앱이라, 키를 숨기는 이득보다 관리가 쉬운 쪽을 택했다.

## 감수하는 위험

누구나 이 키로 "안올툴 업데이트처럼 보이는" APK 를 만들 수 있다. 다만 사용자가 그 APK 를 **직접 받아 설치해야만** 문제가 된다.

- 앱의 자체 업데이트는 설정한 GitHub 저장소의 릴리즈에서만 HTTPS 로 받고, `addons-index.json` 의 sha256 과 비교한 뒤 설치한다.
  자동 업데이트의 안전은 키가 아니라 이 확인에서 나온다.
- 출처를 모르는 안올툴 APK 는 설치하지 않는다.

## 규칙

- 이 파일 하나만 예외다. 다른 키·인증서·토큰은 여전히 커밋하지 않는다 (`.githooks/pre-commit` 이 막는다).
- 키를 바꾸지 않는다. 바꾸면 모든 사용자가 앱을 지우고 다시 설치해야 한다.
- 계정·결제·민감한 데이터를 다루는 기능이 생기면 비공개 키로 옮기는 것을 다시 검토한다.
