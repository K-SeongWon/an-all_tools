# 안올툴 소리 표준

모든 애드온은 이 표준을 따른다. 그래야 애드온을 바꿔도 소리 크기와 느낌이 들쭉날쭉하지 않고,
사용자는 안올툴 설정의 **마스터 / 음성 / 효과음** 세 개만으로 전체 소리를 조절할 수 있다.

코드: `core/src/main/java/com/anall/core/sound/` (HostApi 2 부터)

## 음량 계산

```
최종 음량 = 마스터 볼륨 × 채널 볼륨(음성 또는 효과음) × 표준 레벨
```

- 마스터·채널 볼륨: 사용자가 안올툴 설정에서 0~100% 로 정한다 (기본 마스터 80%, 음성·효과음 100%).
  귀에 고르게 들리도록 제곱 곡선을 쓴다 (50% ≈ -12 dB).
- 표준 레벨: 애드온이 소리의 **종류**에 맞춰 아래 표에서 고른다. 임의의 숫자를 쓰지 않는다.
- 모든 `SoundClip` 은 피크 0 dBFS 로 정규화되어 있다 (`Synth` 가 자동으로 맞춤). 크기는 레벨로만 정한다.
- 피크가 같아도 잡음처럼 뾰족한 소리는 작게 들린다. 그래서 **0.5초가 넘는 소리는 크레스트 팩터(피크 − RMS)를 9 dB 이하**로 맞춘다
  (`Synth.compress` 로 눌러 주고 `Synth.crestFactorDb` 로 확인). 그래야 같은 레벨에서 비슷한 크기로 들린다.
- 결과는 기기의 **미디어 볼륨**을 따르고, 오디오 포커스를 잡지 않아 음악·내비 소리와 섞여서 난다.

## 채널

| 채널 | 용도 |
| --- | --- |
| `SoundChannel.EFFECT` | 버튼음, 기계음, 알림음, 경고음 등 모든 효과음 |
| `SoundChannel.VOICE` | 안내 멘트, TTS 등 사람 목소리 |

## 표준 레벨 (`SoundLevel`)

| 등급 | dBFS | 용도 | 예 |
| --- | ---: | --- | --- |
| `TICK` | -24 | 가볍고 자주 나는 터치·토글 클릭 | 칩 버튼, 스위치 |
| `MECHANICAL` | -20 | 길게 이어지는 기계 동작음 | 영수증 프린터, 모터 |
| `CONFIRM` | -16 | 주요 버튼의 확인음 | 운행 시작/종료 "삑" |
| `NOTIFY` | -12 | 상태 변화 알림 | 할증 시작, 목표 달성 |
| `ALERT` | -8 | 안전·경고 (꼭 들려야 할 때만) | 과속, 위험 |
| `VOICE` | -6 | 음성 안내 (VOICE 채널) | "어디로 모실까요?" |

가장 큰 등급도 -6 dBFS 에서 멈춰서, 여러 소리가 겹쳐도 소리가 깨지지 않는다.

## 표준 효과음 (`Sfx`)

같은 의미의 소리는 애드온이 달라도 같은 소리를 쓴다.

| 소리 | 설명 | 권장 레벨 |
| --- | --- | --- |
| `Sfx.BEEP` | 압전 부저 "삑" (2.7 kHz, 0.13초) | `CONFIRM` |
| `Sfx.DOUBLE_BEEP` | "삑삑" | `CONFIRM` |
| `Sfx.TICK` | 짧은 클릭 "틱" | `TICK` |
| `Sfx.NOTIFY` | 상승 2음 "띵-동" | `NOTIFY` |
| `Sfx.printer(ms)` | 감열 영수증 프린터 "지이잉" + 종이 자르는 "틱" | `MECHANICAL` |

새 효과음이 필요하면 먼저 `Sfx` 에 추가할 수 있는지 본다. 애드온 전용 소리는 `Synth.render { }` 로 만들고 위 레벨 표를 따른다.

## 사용 예

```kotlin
host.playSound(Sfx.BEEP, levelDb = SoundLevel.CONFIRM)                     // 효과음 채널이 기본값
host.playSound(Sfx.printer(1_400), levelDb = SoundLevel.MECHANICAL)
host.playSound(myVoiceClip, SoundChannel.VOICE, SoundLevel.VOICE)
```

## 규칙

- 음원 파일(wav/ogg/mp3)을 넣지 말고 `Synth` 로 만든다 (APK·OTA 패키지를 가볍게 유지).
  꼭 필요한 녹음 소리라면 작게 압축하고 이유를 PR 에 적는다.
- 애드온이 따로 볼륨 설정을 만들지 않는다. "소리 끄기" 같은 애드온 고유 옵션이 필요하면 켜기/끄기만 둔다.
- 운전 중 놀라게 하는 소리 금지: 갑작스러운 큰 소리, 실제 경적·사이렌과 헷갈리는 소리는 쓰지 않는다.
- 반복음(매초 째깍 등)은 `TICK` 이하로 하고, 끌 수 있게 한다.
- 소리를 쓰는 애드온은 `addon.properties` 의 `minHostApi` 를 2 이상으로 둔다.
